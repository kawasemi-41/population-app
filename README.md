# 首都圏人口一覧アプリ

## 概要

本アプリケーションは、e-Stat API（政府統計API）から首都圏8都県の総人口データを取得し、年度ごとの人口を表形式で表示するReactアプリケーションです。
また、友好度情報を定義したCSVファイルを利用して、友好度の総和が最大となるように都県を3グループ以下へ分類し、結果を人口表へ反映して表示します。

---

## 対象都県

- 茨城県
- 栃木県
- 群馬県
- 埼玉県
- 千葉県
- 東京都
- 神奈川県
- 山梨県

## 主な機能

### 1. 人口データ取得

e-Stat APIから人口データを取得します。

取得データ

- 都道府県名
- 年度
- 総人口

表示形式

|項目|内容|
|---|---|
|横軸|都県名|
|縦軸|年度|
|並び順|年度降順|

---

### 2. ページング

人口表は20件単位で表示します。

機能

- 前へ
- 次へ
- ページ番号選択

---

### 3. 最適グループ分け

CSVに定義された友好度情報を利用して、友好度総和が最大となるグループ分けを実行します。

制約条件

- グループ数は3以下
- 全都県を必ずいずれかのグループへ所属させる

---

### 4. 友好度結果表示

画面上部にグループ分け結果を表示します。

表示内容

- 最大友好度
- 各グループの友好度
- グループ構成

Bootstrap Accordionを利用し、初期状態では閉じています。

---

### 5. 人口表の色分け

グループ分け結果に応じて人口表の列を色分けします。

|グループ|色|
|---|---|
|グループ1|薄赤|
|グループ2|薄青|
|グループ3|薄緑|

※ 列ヘッダーは色分け対象外です。

---

## サンプルデータ

グループ分け用CSVは以下を使用します。
画面表示時に読み込まれます。

```text
public/csv/sample.csv
```

---

## アルゴリズム

グループ分けは総当たり方式で実装しています。

処理概要

1. 各都県に対してグループ番号を割り当てる
2. グループ数が3以下となるパターンを生成
3. グループ内友好度を計算
4. 合計友好度が最大の組み合わせを採用
